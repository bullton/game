# 红白机经典游戏网站 - 产品需求文档

## 1. 产品概述

一个汇集众多经典红白机(Famicom/NES)游戏的在线游戏平台，用户可注册账号、在线游玩经典游戏，并基于每种游戏进行全球排名竞争。

- 目标用户：怀旧游戏爱好者、复古游戏玩家
- 市场价值：为经典游戏爱好者提供一站式游玩和竞技平台

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 邮箱注册/登录 | 浏览游戏列表、在线玩游戏、提交分数、查看排行榜 |
| 管理员 | 后台分配 | 管理游戏内容、管理用户、审核分数、系统配置 |

### 2.2 功能模块

1. **首页**: 游戏展示区、热门游戏推荐、用户登录入口
2. **游戏列表页**: 所有游戏分类展示、搜索和筛选功能
3. **游戏详情页**: 游戏介绍、在线游戏界面、该游戏排行榜
4. **排行榜页**: 所有游戏综合排名、按游戏筛选排名
5. **用户中心**: 个人信息、我的成绩、账号设置
6. **登录/注册页**: 用户认证系统

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 游戏展示区 | 展示热门游戏卡片，点击跳转到游戏详情 |
| 首页 | 用户登录 | 登录/注册按钮，显示当前用户信息 |
| 游戏列表页 | 游戏网格 | 所有游戏以卡片形式展示，支持分类筛选 |
| 游戏列表页 | 搜索功能 | 按游戏名称搜索游戏 |
| 游戏详情页 | 游戏模拟器 | 内嵌Web模拟器，可直接在线游玩 |
| 游戏详情页 | 游戏信息 | 游戏简介、发行商、年份等信息 |
| 游戏详情页 | 排行榜 | 该游戏的Top 50排名，显示用户名和分数 |
| 排行榜页 | 综合排名 | 所有游戏的排名列表，支持按游戏筛选 |
| 用户中心 | 个人信息 | 头像、用户名、注册时间 |
| 用户中心 | 我的成绩 | 用户在各个游戏中的成绩记录 |
| 登录/注册页 | 认证表单 | 邮箱和密码登录/注册 |

## 3. 核心流程

### 用户游玩流程

```
用户访问首页 → 浏览游戏列表 → 选择游戏 → 进入游戏详情 → 登录(如未登录) → 开始游戏 → 获得分数 → 提交分数 → 查看排行榜
```

### 用户注册流程

```
用户访问首页 → 点击注册 → 填写邮箱和密码 → 提交注册 → 登录成功 → 进入首页
```

### 排行榜提交流程

```
用户玩游戏 → 游戏结束 → 弹出分数提交框 → 输入分数 → 提交 → 更新排行榜 → 显示排名位置
```

## 4. 用户界面设计

### 4.1 设计风格

- **主题风格**: 复古像素风(Retro Pixel Art)，致敬80年代红白机时代
- **主色调**: 
  - 深蓝色背景 (#0a0e27) - 模拟老式电视屏幕
  - 霓虹红色 (#ff2d55) - 强调色，按钮和链接
  - 霓虹蓝色 (#00d4ff) - 次要强调色
  - 霓虹绿色 (#30d158) - 成功状态和高分提示
- **按钮风格**: 圆角矩形，带霓虹发光效果
- **字体**: 使用像素风格字体显示标题，现代无衬线字体显示正文
- **布局风格**: 卡片式布局，网格展示游戏
- **图标风格**: 像素风格图标

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | Hero区域 | 大标题带像素动画效果，渐变背景，游戏角色剪影 |
| 首页 | 游戏卡片 | 3D翻转效果，悬停时显示霓虹发光边框 |
| 游戏列表页 | 游戏网格 | 响应式网格布局，卡片带像素风缩略图 |
| 游戏详情页 | 模拟器容器 | 复古游戏机边框样式，屏幕带CRT扫描线效果 |
| 游戏详情页 | 排行榜表格 | 像素风格表格，前三名带奖牌图标和特殊样式 |
| 用户中心 | 信息面板 | 卡片式布局，带用户头像和统计信息 |

### 4.3 响应式设计

- 桌面端优先设计，支持1920px、1440px、1024px断点
- 平板端适配：游戏网格调整为3列
- 移动端适配：游戏网格调整为2列，导航改为汉堡菜单

### 4.4 动画效果

- 页面加载时游戏卡片依次淡入动画
- 悬停游戏卡片时显示霓虹发光效果
- 排行榜更新时分数高亮闪烁
- 游戏开始时有复古启动动画效果
